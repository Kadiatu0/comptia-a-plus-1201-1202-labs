# Lab 4 – Choose and Install a Motherboard

## Scenario

As a computer repair technician, I was tasked with selecting and installing a motherboard that met specific customer requirements for a new desktop system.

---

## Objectives

- Select a compatible motherboard.
- Install the motherboard into the case.
- Connect case headers and power cables.

---

## Technologies

- Socket 1151 Motherboard
- PCI Express Support
- USB Headers
- Front Panel Connectors
- ATX Power Connectors

---

## Skills Demonstrated

- Motherboard Compatibility Checking
- Hardware Installation
- Front Panel Wiring
- Power Cable Connection

---

## Procedure

1. Reviewed motherboard specifications to find a model that met the required features.
2. Installed the Socket 1151 motherboard into the computer case.
3. Located motherboard connection points using documentation.
4. Connected case connectors:
   - USB 3.0
   - Front Audio
   - USB 2.0
   - Front and Rear Fans
   - Speaker
   - HDD LED
   - Power LED
   - Power Switch
5. Connected power supply cables:
   - 8-pin CPU power connector
   - 20+4 pin motherboard power connector
6. Verified all motherboard connections were properly installed.

---

## Outcome

Successfully selected and installed a compatible motherboard and connected all required case and power cables.

---

## Key Takeaways

- Learned how to verify motherboard specifications before installation.
- Practiced connecting motherboard headers and power cables.
- Improved desktop assembly skills.
