# Lab 8 – Install a Power Supply

## Scenario

As an IT administrator, I was tasked with replacing a computer power supply and connecting all required power cables to restore system operation.

---

## Objectives

- Select a compatible power supply.
- Install and connect PSU cables.
- Verify successful system startup.

---

## Technologies

- ATX Power Supply
- 24-Pin Motherboard Connector
- 8-Pin CPU Connector
- SATA Power Connectors

---

## Skills Demonstrated

- Power Supply Installation
- Cable Identification
- Hardware Configuration

---

## Procedure

1. Reviewed motherboard documentation to identify required power connectors.
2. Selected a power supply with:
   - 24-pin motherboard connector
   - 8-pin CPU connector
   - SATA power connectors
3. Installed the power supply into the computer case.
4. Connected:
   - 24-pin motherboard power cable
   - 8-pin CPU power cable
   - SATA power cables to three hard drives
5. Connected the computer to wall power.
6. Turned on the power supply switch.
7. Powered on the computer and verified successful startup.

---

## Outcome

Successfully installed a compatible power supply and restored power to the computer system.

---

## Key Takeaways

- Learned how to select a PSU based on motherboard requirements.
- Practiced connecting different power cables.
- Improved hardware installation skills.
