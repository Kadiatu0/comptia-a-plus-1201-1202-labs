# Lab 11 – Select Memory by Sight

## Scenario

As a computer repair technician, I was assigned to install the correct memory module based on the motherboard's memory slot design.

---

## Objectives

- Identify the correct RAM type.
- Match memory modules with motherboard slots.
- Install compatible memory.

---

## Technologies

- DDR4 RAM
- Motherboard Memory Slots
- Memory Modules

---

## Skills Demonstrated

- Hardware Identification
- RAM Compatibility Checking
- Memory Installation

---

## Procedure

1. Switched to the motherboard view.
2. Examined the memory slots and identified the notch placement.
3. Determined that the motherboard required DDR4 memory.
4. Installed the RAM module into the appropriate motherboard slot.

---

## Outcome

Successfully identified and installed the correct DDR4 memory module.

---

## Key Takeaways

- Learned how to identify RAM types by physical design.
- Practiced matching memory modules to motherboard slots.
- Improved hardware installation skills.
