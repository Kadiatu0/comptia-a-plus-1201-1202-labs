# Lab 12 – Install Triple Channel Memory

## Scenario

As a computer repair technician, I was tasked with installing and configuring memory in a system using an Intel i7 processor. The goal was to achieve triple-channel memory operation.

---

## Objectives

- Identify supported memory specifications.
- Install compatible RAM modules.
- Verify triple-channel configuration.

---

## Technologies

- DDR3 RAM
- Triple-Channel Memory
- BIOS Configuration
- Motherboard Memory Slots

---

## Skills Demonstrated

- RAM Installation
- Hardware Compatibility Checking
- BIOS Verification

---

## Procedure

1. Reviewed motherboard documentation to identify supported memory:
   - Maximum supported speed: 1600 MHz
   - Recommended slots: DIMM_A1, DIMM_B1, and DIMM_C1
2. Installed three DDR3 2GB 1600 MHz memory modules.
3. Placed the modules in the three recommended blue memory slots.
4. Booted the computer and entered BIOS using F2.
5. Verified that all memory was detected and operating in triple-channel mode.

---

## Outcome

Successfully installed and configured 6GB of DDR3 memory running in triple-channel mode.

---

## Key Takeaways

- Learned how to follow motherboard memory installation guidelines.
- Practiced configuring triple-channel RAM.
- Verified memory settings through BIOS.
