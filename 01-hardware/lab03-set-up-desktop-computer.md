# Lab 3 – Set Up a Desktop Computer

## Scenario

As an IT administrator, I was assigned to set up and configure a new desktop workstation for a corporate environment.

---

## Objectives

- Connect computer hardware and peripherals.
- Provide power to all devices.
- Connect the computer to the network.
- Verify system operation.

---

## Technologies

- Desktop Computer
- Power Strip
- USB Peripherals
- DVI Display Connection
- Ethernet Connection
- Printer

---

## Skills Demonstrated

- Workstation Setup
- Peripheral Installation
- Network Connectivity
- Hardware Configuration

---

## Procedure

1. Connected a power strip to the wall outlet.
2. Connected power cables for:
   - Computer
   - Monitor
   - Printer
3. Connected peripherals:
   - Keyboard
   - Mouse
   - Speakers
4. Connected the monitor to the computer using a DVI cable.
5. Connected the printer using a USB cable.
6. Connected the printer power adapter.
7. Connected the computer to the network using a Cat6a Ethernet cable.
8. Powered on the monitor and computer.
9. Verified that the system started successfully.

---

## Outcome

Successfully installed and configured a complete desktop workstation with peripherals, printer, and network connectivity.

---

## Key Takeaways

- Learned the proper process for desktop deployment.
- Practiced connecting different hardware interfaces.
- Improved skills in workstation setup and network connections.
