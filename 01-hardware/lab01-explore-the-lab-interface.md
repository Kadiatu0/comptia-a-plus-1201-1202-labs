# Lab 01 – Explore the Lab Interface

## Scenario

As a newly hired network technician for a small corporate network, I was tasked with becoming familiar with the network environment and preparing a workstation for a new employee in Office 2.

---

## Objectives

- Navigate the networking closet and office workspace.
- Set up a monitor and workstation components.
- Connect display and peripheral devices.
- Verify the computer system powers on correctly.

---

## Technologies

- Desktop Computer
- HDMI Connection
- Monitor
- Keyboard and Mouse
- Computer Power Connections

---

## Skills Demonstrated

- Workstation Setup
- Peripheral Installation
- Cable Identification
- Basic Hardware Troubleshooting

---

## Procedure

1. Navigated from the networking closet to Office 2.
2. Added a monitor to the employee workstation.
3. Connected the monitor to the computer using an HDMI cable.
4. Connected the monitor power cable.
5. Installed the keyboard and mouse.
6. Connected the keyboard and mouse to the back of the computer.
7. Powered on the monitor and computer.
8. Verified the workstation started successfully.

---

## Outcome

Successfully prepared the Office 2 workstation for a new employee by installing and connecting all required hardware components.

---

## Key Takeaways

- Learned how to identify common workstation components.
- Practiced connecting computer peripherals.
- Improved understanding of basic desktop setup procedures.
