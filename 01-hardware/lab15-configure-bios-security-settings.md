# Lab 15 – Configure BIOS Security Settings

## Scenario

As an IT technician, I was assigned to configure BIOS security settings to protect the computer system and storage devices.

---

## Objectives

- Set BIOS administrator password.
- Configure hard drive password.
- Enable TPM security.
- Enable chassis intrusion detection.

---

## Technologies

- BIOS/UEFI Security Settings
- TPM Security
- Hard Drive Password Protection
- Chassis Intrusion Detection

---

## Skills Demonstrated

- BIOS Configuration
- System Security Setup
- Firmware Security Management

---

## Procedure

1. Restarted the computer and accessed BIOS using F2.
2. Set the BIOS administrator password.
3. Configured a password for the internal hard drive.
4. Enabled TPM security and applied the changes.
5. Enabled chassis intrusion detection.
6. Saved BIOS changes and restarted the system.
7. Verified the administrator password and hard drive password worked correctly.

---

## Outcome

Successfully configured BIOS security features, including password protection, TPM, and chassis intrusion detection.

---

## Key Takeaways

- Learned how to secure a system through BIOS settings.
- Practiced configuring firmware-level security options.
- Improved understanding of hardware security features.
