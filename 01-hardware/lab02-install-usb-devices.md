# Lab 02 – Install USB Devices

## Scenario

As an IT helpdesk technician, I was responsible for creating a testing station used to evaluate different computer peripherals and USB devices.

---

## Objectives

- Install a USB hub.
- Connect multiple USB devices.
- Verify proper USB connectivity.

---

## Technologies

- USB Hub
- USB 2.0/3.0 Devices
- Inkjet Printer
- Laser Printer
- Scanner
- External USB Storage

---

## Skills Demonstrated

- USB Device Installation
- Peripheral Configuration
- Hardware Connectivity Testing

---

## Procedure

1. Placed the USB hub on the workstation bench.
2. Connected the USB hub to the computer.
3. Connected the following devices to the USB hub:
   - Inkjet Printer
   - Laser Printer
   - Scanner
4. Added the portable USB hard drive to the workspace.
5. Connected the portable hard drive directly to the computer.
6. Verified that all USB devices were properly connected.

---

## Outcome

Successfully configured a USB testing station with multiple peripherals connected and ready for troubleshooting and evaluation.

---

## Key Takeaways

- Learned how USB hubs expand computer connectivity.
- Practiced connecting multiple USB peripherals.
- Improved understanding of peripheral installation.
