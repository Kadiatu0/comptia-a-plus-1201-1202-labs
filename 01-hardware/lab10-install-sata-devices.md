# Lab 10 – Install SATA Devices

## Scenario

As a computer repair technician, I was assigned to install SATA hard drives into a desktop computer and connect them correctly to the motherboard and power supply.

---

## Objectives

- Identify SATA ports on the motherboard.
- Install SATA hard drives.
- Connect SATA data and power cables.

---

## Technologies

- SATA Hard Drives
- SATA Data Cables
- SATA Power Connectors
- Motherboard SATA Ports

---

## Skills Demonstrated

- Storage Installation
- Cable Connection
- Hardware Configuration

---

## Procedure

1. Reviewed motherboard documentation to locate SATA ports.
2. Installed two SATA hard drives into available 3.5-inch drive bays.
3. Connected SATA data cables from each hard drive.
4. Connected the SATA cables to the motherboard ports.
5. Connected SATA power connectors from the power supply to both drives.
6. Verified all storage connections were properly installed.

---

## Outcome

Successfully installed and connected two SATA hard drives, preparing the system for storage use.

---

## Key Takeaways

- Learned how to locate motherboard SATA ports.
- Practiced installing internal storage devices.
- Improved understanding of SATA data and power connections.
