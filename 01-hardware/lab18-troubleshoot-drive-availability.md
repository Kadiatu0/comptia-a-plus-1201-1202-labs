# Lab 18 – Troubleshoot Drive Availability

## Scenario

As a computer repair technician, I was assigned to troubleshoot a used computer that failed to boot after a hard drive replacement. The goal was to verify drive detection and configure the system to boot correctly into Windows.

---

## Objectives

- Verify drive availability in BIOS/UEFI.
- Configure boot order settings.
- Restore normal Windows startup.

---

## Technologies

- BIOS/UEFI Firmware
- SATA Hard Drive
- Boot Sequence Configuration
- Windows Operating System

---

## Skills Demonstrated

- BIOS Configuration
- Boot Troubleshooting
- Storage Device Verification

---

## Procedure

1. Powered on the computer and confirmed the boot failure.
2. Entered BIOS/UEFI using F2.
3. Checked the Drives settings and verified all connected drives were enabled.
4. Reviewed the boot sequence settings.
5. Enabled the Internal HDD as a boot option.
6. Moved the internal hard drive to the primary boot position.
7. Saved BIOS changes and exited the configuration menu.
8. Verified the computer successfully booted into Windows.

---

## Outcome

Successfully configured BIOS boot settings and restored the computer’s ability to start Windows using the installed hard drive.

---

## Key Takeaways

- Learned how BIOS detects and manages storage devices.
- Practiced correcting boot order issues.
- Improved troubleshooting skills for drive availability problems.
