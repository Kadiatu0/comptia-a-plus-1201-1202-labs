# Lab 20 – Resolve PC Hardware Support Tickets

## Scenario

As an IT helpdesk technician, I was assigned three high-priority hardware support tickets. My task was to troubleshoot each issue, restore system functionality, document the repairs, and close the tickets.

---

## Objectives

- Troubleshoot multiple hardware issues.
- Restore affected workstations.
- Document repairs in the ticketing system.

---

## Technologies

- Issue Trax
- RAM Modules
- HDMI Cable
- Surge Protector
- Desktop Workstations

---

## Skills Demonstrated

- Hardware Troubleshooting
- Helpdesk Ticket Management
- Component Installation
- User Support

---

## Procedure

1. Opened Issue Trax and reviewed all assigned support tickets.
2. **Ticket 11:** Restored power by turning on the surge protector and verified the computer started normally.
3. **Ticket 12:** Identified missing RAM, installed two memory modules, and confirmed the system booted successfully.
4. **Ticket 13:** Connected the disconnected HDMI cable between the computer and monitor, restoring the display.
5. Added professional repair notes to each ticket and marked them as closed.

---

## Outcome

Successfully resolved all three hardware issues, restored the affected computers to working condition, and completed the required ticket documentation.

---

## Key Takeaways

- Practiced troubleshooting common desktop hardware issues.
- Improved helpdesk documentation and ticket management skills.
- Reinforced the importance of checking basic hardware connections before replacing components.
