# Lab 13 – Troubleshoot Memory

## Scenario

As an IT helpdesk technician, I was assigned a ticket for a computer that failed to boot due to a suspected memory problem.

---

## Objectives

- Identify faulty RAM.
- Replace bad memory.
- Verify system operation.
- Document the repair.

---

## Technologies

- RAM Modules
- Memory Tester
- Motherboard
- Ticket System

---

## Skills Demonstrated

- Memory Troubleshooting
- Hardware Replacement
- Ticket Documentation

---

## Procedure

1. Opened Issue Trax and reviewed the support ticket.
2. Tested the computer and confirmed it would not boot and produced beeping sounds.
3. Used the Memory Tester to check each RAM module.
4. Identified and removed the faulty RAM stick.
5. Tested replacement RAM modules and installed working 2GB sticks.
6. Verified the system had 8GB of RAM installed.
7. Booted the computer and confirmed Windows loaded successfully.
8. Added repair notes and closed the ticket.

---

## Outcome

Successfully replaced the defective RAM module and restored the computer to working condition.

---

## Key Takeaways

- Learned how to test and replace faulty RAM.
- Practiced diagnosing boot issues.
- Improved hardware troubleshooting skills.
