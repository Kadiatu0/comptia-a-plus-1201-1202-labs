# Lab 14 – Access and Configure BIOS Settings

## Scenario

As an IT technician, I was assigned to review a computer’s BIOS settings and verify important hardware configuration information.

---

## Objectives

- Access the BIOS setup utility.
- Identify system hardware information.
- Verify device configuration settings.

---

## Technologies

- BIOS/UEFI Firmware
- Intel Processor
- System Memory
- Integrated NIC
- USB Controller

---

## Skills Demonstrated

- BIOS Navigation
- Hardware Identification
- System Configuration Verification

---

## Procedure

1. Restarted the computer and entered BIOS setup using the F2 key.
2. Reviewed system information and verified:
   - BIOS Version: 1610
   - Installed Memory: 16384 MB
   - Processor Manufacturer: Intel
   - Installed Hard Drives: 3
3. Checked integrated device settings:
   - Integrated NIC: Enabled
   - USB 3.0 Controller: Enabled
4. Submitted the lab results and verified completion.

---

## Outcome

Successfully accessed BIOS and identified system hardware information and configuration settings.

---

## Key Takeaways

- Learned how to access and navigate BIOS settings.
- Practiced identifying installed hardware information.
- Improved understanding of firmware-level system configuration.
