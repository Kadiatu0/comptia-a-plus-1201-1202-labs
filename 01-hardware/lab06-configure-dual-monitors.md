# Lab 6 – Configure Dual Monitors

## Scenario

As an IT technician, I was tasked with upgrading a workstation by installing a video card and configuring a dual-monitor setup for improved productivity.

---

## Objectives

- Install a PCIe video card.
- Connect multiple monitors.
- Configure display settings.

---

## Technologies

- PCIe Video Card
- DVI Connection
- HDMI Connection
- 6-Pin PCIe Power Connector
- Dual Monitor Configuration

---

## Skills Demonstrated

- Graphics Card Installation
- Display Configuration
- Hardware Troubleshooting

---

## Procedure

1. Powered off the computer and installed a PCIe video card.
2. Connected the 6-pin PCIe power connector to the graphics card.
3. Connected the original monitor to the new video card using DVI.
4. Connected the second monitor using HDMI.
5. Powered on the system and opened display settings.
6. Set the new monitor as the main display.
7. Identified and arranged the monitors to match their physical placement.
8. Applied the display configuration.

---

## Outcome

Successfully installed a video card and configured a dual-monitor workstation with the correct display arrangement.

---

## Key Takeaways

- Learned how to install a PCIe graphics card.
- Practiced connecting DVI and HDMI displays.
- Improved skills configuring multiple monitors.
