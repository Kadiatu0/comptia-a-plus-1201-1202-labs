# Lab 7 – Set Up an A/V Workstation

## Scenario

As an IT technician, I was tasked with upgrading a video editing workstation by adding improved graphics support, dual monitors, and a reliable RAID 5 storage solution.

---

## Objectives

- Install a graphics card.
- Configure dual monitors.
- Install multiple hard drives.
- Create a RAID 5 storage array.

---

## Technologies

- PCIe Video Card
- HDMI and DVI Connections
- SATA Hard Drives
- RAID 5 Storage
- BIOS RAID Configuration

---

## Skills Demonstrated

- Hardware Upgrades
- Storage Configuration
- RAID Setup
- Display Installation

---

## Procedure

1. Installed a PCIe video card and connected the 6-pin PCIe power cable.
2. Installed three SATA hard drives for RAID 5 configuration.
3. Connected SATA data and power cables to all drives.
4. Connected the original monitor to the new video card using DVI.
5. Installed a second monitor using HDMI.
6. Enabled RAID mode in the BIOS settings.
7. Created a RAID 5 array using three hard drives.
8. Verified the RAID configuration was successfully created.

---

## Outcome

Successfully upgraded the A/V workstation with dual-monitor support and a RAID 5 storage solution that provides improved performance and data redundancy.

---

## Key Takeaways

- Learned how to install and configure a PCIe graphics card.
- Practiced setting up RAID 5 storage.
- Improved skills in workstation upgrades and hardware configuration.
