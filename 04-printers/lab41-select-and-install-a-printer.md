# Lab 41 – Select and Install a Printer

## Scenario

You are an IT administrator for a corporate network. You have been asked to install a new USB laser printer in Office 2. The printer must be placed in the workspace, connected to the computer with a data cable, and connected to a wall outlet for power.

## Objectives

- Add a laser printer to the workspace.
- Connect the printer to the computer using a USB cable.
- Connect the printer to a power outlet.
- Identify the correct printer ports and cable connectors.

## Technologies

- USB laser printer
- USB Cable A/B
- AC power cable
- Desktop computer
- USB ports
- Electrical wall outlet

## Skills Demonstrated

- Installing a printer
- Connecting USB peripherals
- Identifying USB Type-A and Type-B connectors
- Connecting printer power
- Setting up computer hardware peripherals

## Procedure

1. Add the laser printer to the workspace.
   - Under Inventory, expand **Peripherals**.
   - Drag **Printer, Laser, USB** to the workspace.

2. Connect the printer to the computer.
   - Switch to the **Back** view of the printer.
   - Switch to the **Back** view of the computer tower.
   - Under Inventory, select **Peripherals**, then **Cables**.
   - Select **USB Cable A/B**.
   - Drag the Type-A connector to an available USB port on the back of the computer.
   - Drag the Type-B connector to the Type-B USB port on the back of the printer.

3. Connect power to the printer.
   - Under Inventory, select **AC Power Cable**.
   - Drag the male connector to the wall outlet.
   - Drag the female connector to the power port on the back of the printer.

4. Verify that the printer's data and power cables are connected correctly.

## Outcome

Successfully added the USB laser printer to the workspace, connected it to the computer using a USB A/B data cable, and connected it to the wall outlet using an AC power cable.

## Key Takeaways

- Learned how to install a USB laser printer.
- Identified the difference between USB Type-A and Type-B connectors.
- Practiced connecting a printer to a computer using a USB data cable.
- Learned how to connect a printer to an electrical outlet.
- Understood that printers need both a data connection and a power source to operate.
