# Lab 46 – Resolve Print Services Support Tickets

## Scenario

You are an IT administrator working from the ITAdmin computer. At the beginning of the day, you check Issue Trax for open help desk tickets. Your task is to review the printer-related issues, install the required printers, configure the default printer when needed, document the completed work, and close the tickets.

## Objectives

- Review open printer support tickets in Issue Trax.
- Install an HP Photosmart Plus printer.
- Connect the printer to the laptop and a power source.
- Set the HP Photosmart Plus as the default printer.
- Install an Okidata dot-matrix printer in the IT Office.
- Add resolution comments and close both tickets.

## Technologies

- Issue Trax help desk system
- HP Photosmart Plus printer
- Okidata dot-matrix printer
- USB Type-A and Type-B cable
- HP power adapter
- Windows printer settings

## Skills Demonstrated

- Reviewing and resolving help desk tickets
- Installing printer hardware
- Connecting printer data and power cables
- Configuring a default printer
- Installing a dot-matrix printer
- Documenting support work
- Closing resolved tickets

## Procedure

### Ticket #20 – Install the HP Photosmart Plus

1. On ITAdmin, open **Issue Trax** from the taskbar search.
2. Maximize the window.
3. Select ticket **#20** and review Gerry's request to determine the required printer and solution.
4. Select **Floor 1 Overview**.
5. Under Lobby, select **Hardware**.
6. Expand **Peripherals** in Inventory.
7. Drag the **HP Photosmart Plus** printer to the workspace.
8. Switch to the back view of the laptop and printer.
9. Under Inventory, return to **Peripherals** and expand **Cables**.
10. Select **USB Cable (A/B)**.
11. Connect the USB Type-B connector to the printer.
12. Connect the USB Type-A connector to an available USB port on the laptop.
13. Under Inventory, select **Power Adapter for HP**.
14. Connect the DC connector to the printer's power port.
15. Connect the AC connector to the wall outlet.
16. Switch to the front view of the laptop and select the monitor.
17. Open **Settings** by right-clicking **Start**.
18. Select **Bluetooth & devices > Printers & scanners**.
19. Select **HP Photosmart Plus**.
20. Select **Set as default**.
21. Return to ITAdmin and open ticket #20 in Issue Trax.
22. Enter a comment confirming that the printer was installed.
23. Select the **+** button to add the comment.
24. Change the ticket status to **Closed**.
25. Select the left arrow to view the remaining ticket.

### Ticket #21 – Install the Okidata Dot-Matrix Printer

1. Select ticket **#21** in Issue Trax.
2. Select **IT Administration**.
3. Under Peripherals in Inventory, locate the **Okidata** dot-matrix printer.
4. Drag the printer to the workspace in the IT Office.
5. Return to the operating system by selecting the monitor.
6. Add a comment to ticket #21 confirming that the requested job is complete.
7. Select the **+** button to submit the comment.
8. Change the ticket status to **Closed**.

## Outcome

Successfully reviewed and resolved two printer support tickets. Installed and connected the HP Photosmart Plus printer, configured it as the default printer, and added the Okidata dot-matrix printer to the IT Office workspace. Documented the work in Issue Trax and closed both tickets.

## Key Takeaways

- Help desk tickets should be reviewed to identify the requested solution.
- Printers may require both a data connection and a separate power connection.
- Windows printer settings can be used to configure the default printer.
- Different printer types, including inkjet and dot-matrix printers, serve different needs.
- Resolution comments document the work completed for each ticket.
- Tickets should be closed after the requested work has been completed and documented.
