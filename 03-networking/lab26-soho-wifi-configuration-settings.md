# Lab 26 – SOHO Wi-Fi Configuration Settings

## Scenario

As an IT technician, I was tasked with customizing a SOHO wireless access point by changing its administrator credentials and optimizing its wireless configuration.

---

## Objectives

- Change the default administrator credentials.
- Configure the wireless mode.
- Enable automatic wireless channel selection.

---

## Technologies

- Wireless Access Point
- 802.11g/n
- Wireless Channel Selection
- Google Chrome
- SOHO Network

---

## Skills Demonstrated

- Wireless Access Point Configuration
- Network Security
- Wireless Optimization
- Administrator Account Management

---

## Procedure

1. Accessed the TRENDnet wireless access point through Chrome using `192.168.0.254`.
2. Logged in using the default administrator credentials.
3. Changed the wireless mode to **802.11 g/n mixed mode**.
4. Configured the wireless channel to **AutoSelect**.
5. Applied the wireless settings.
6. Changed the administrator username and password from the default credentials.
7. Applied the new administrator settings.
8. Closed the configuration interface.

---

## Outcome

Successfully customized the SOHO wireless access point by securing the administrator account, configuring mixed wireless mode, and enabling automatic channel selection.

---

## Key Takeaways

- Learned how to change default wireless administrator credentials.
- Practiced configuring wireless modes and channels.
- Improved understanding of basic SOHO wireless security.
