# Lab 24 – Connect Computers with a Switch

## Scenario

As a network technician, I was tasked with designing a small office/home office (SOHO) network by connecting multiple computers to a switch and connecting the switch to a router.

---

## Objectives

- Build a basic SOHO network.
- Connect computers to a network switch.
- Connect the switch to a router.
- Verify proper network topology.

---

## Technologies

- Ethernet
- Network Switch
- Router
- End Devices
- SOHO Network

---

## Skills Demonstrated

- Network Topology Design
- Switch Configuration
- Ethernet Connections
- Router Connectivity

---

## Procedure

1. Added three computers to the network modeler canvas.
2. Added a network switch to the canvas.
3. Connected each computer's Ethernet port to an available switch port.
4. Added a router to the network.
5. Connected the switch to the router using an available network port.
6. Verified that all devices were connected to the network topology.

---

## Outcome

Successfully designed a basic SOHO network with three computers connected to a switch and the switch connected to a router.

---

## Key Takeaways

- Learned how to build a basic network topology.
- Practiced connecting end devices to a switch.
- Learned how switches and routers work together in a network.
