# Lab 38 – Manage Mobile Devices

## Scenario

You are the IT administrator for a small corporate network. The CFO, Arlene Kimbly, has purchased an iPad and needs to transfer data to her laptop using Bluetooth. The iPad must also connect to the CorpNet wireless network and have VPN settings configured for future use.

## Objectives

- Connect the iPad to the CorpNet wireless network.
- Enable Bluetooth.
- Configure VPN settings.
- Do not connect to the VPN.

## Technologies

- iPad
- Wi-Fi
- Bluetooth
- VPN
- PPTP

## Skills Demonstrated

- Configuring mobile Wi-Fi
- Configuring Bluetooth
- Configuring mobile VPN settings
- Managing iPad network settings

## Procedure

1. Open **Settings** on the iPad.
2. Select **Wi-Fi**.
3. Turn Wi-Fi on.
4. Under Networks, select `CorpNet`.
5. Enter the password `@CorpNetWeRSecure!&`.
6. Select **Join**.
7. Select **Bluetooth**.
8. Turn Bluetooth on.
9. Select **General**.
10. Select **VPN**.
11. Select **Add VPN Configuration**.
12. Select **PPTP**.
13. Configure the VPN settings:
    - Description: `CorpNet VPN`
    - Server: `198.10.20.12`
    - Account: `akimbly`
14. Select **Save**.
15. Leave the VPN disconnected.

## Outcome

Successfully connected the iPad to the CorpNet wireless network, enabled Bluetooth, and configured the CorpNet VPN settings for future use without connecting to the VPN.

## Key Takeaways

- Learned how to configure Wi-Fi on an iPad.
- Practiced enabling Bluetooth.
- Learned how to configure a PPTP VPN.
- Practiced managing mobile device network settings.
