# Lab 39 – Configure a Laptop Dock and External Peripherals

## Scenario

A company field employee uses a laptop as their primary PC. They need an easy way to connect the laptop to a monitor and external peripherals when working in the office. A USB-C dock will be installed so the employee can connect the laptop using one cable.

## Objectives

- Install a USB-C dock.
- Connect the office peripherals to the dock.
- Configure the setup so the laptop can connect to the monitor and peripherals through the dock.

## Technologies

- Laptop
- USB-C
- USB-C docking station
- External monitor
- External peripherals

## Skills Demonstrated

- Installing a laptop docking station
- Connecting external peripherals
- Using USB-C connectivity
- Configuring a laptop for office peripherals

## Procedure

1. Install the USB-C dock in the office.
2. Connect the monitor to the docking station.
3. Connect the required external peripherals to the docking station.
4. Connect the USB-C dock to the laptop using the dock's USB-C connection.
5. Verify that the laptop can use the connected monitor and external peripherals.

## Outcome

Successfully configured a USB-C docking setup that allows the employee to connect the laptop to the office monitor and external peripherals using a single cable.

## Key Takeaways

- Learned how docking stations simplify laptop connectivity.
- Practiced connecting external peripherals through a USB-C dock.
- Learned how a single USB-C connection can provide access to multiple office peripherals.
