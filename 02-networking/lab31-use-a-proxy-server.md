# Lab 31 – Use a Proxy Server

## Scenario

As an IT administrator for a small corporate network, I configured the Marketing6 computer to use the company's proxy server. The proxy server is used to control access to the internet.

---

## Objectives

- Access the Windows proxy settings.
- Configure a manual proxy server.
- Configure the corporate proxy server address.
- Configure the proxy server port.
- Save the proxy configuration.

---

## Technologies

- Proxy Server
- Windows 11
- Network & Internet Settings
- Manual Proxy Configuration
- DNS / Hostname Resolution
- TCP/IP
- Internet Access Control

---

## Skills Demonstrated

- Proxy Server Configuration
- Windows Network Configuration
- Manual Proxy Configuration
- Network Settings Management
- Internet Access Configuration
- Troubleshooting Network Connectivity

---

## Procedure

1. Opened **Settings** by right-clicking **Start** and selecting **Settings**.
2. Selected **Network & Internet**.
3. Selected **Proxy** from the left pane.
4. Maximized the Settings window for easier viewing.
5. Under **Manual proxy setup**, enabled **Use a proxy server**.
6. Entered the following proxy server address:
   - Proxy Address: **proxy.corpnet.local**
   - Port: **9000**
7. Selected **Save**.
8. Closed the Settings application.
9. Verified that the manual proxy configuration was saved successfully.

---

## Outcome

Successfully configured the Marketing6 computer to use the corporate proxy server **proxy.corpnet.local** on port **9000**.

---

## Key Takeaways

- Learned how to access proxy settings in Windows.
- Practiced configuring a manual proxy server.
- Learned how proxy servers can control internet access.
- Practiced configuring a proxy server hostname and port.
- Learned how network proxy settings are managed through Windows Settings.
