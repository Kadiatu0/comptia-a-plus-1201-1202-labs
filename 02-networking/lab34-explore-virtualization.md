# Lab 34 – Explore Virtualization

## Scenario

In this lab, I explored virtualization by using Hyper-V Manager to run three virtual machines on the ITAdmin computer. I examined the operating system installed on the physical computer and each virtual machine.

---

## Objectives

- Explore Hyper-V Manager.
- Launch virtual machines.
- Identify the operating system running on the physical computer.
- Identify the operating system running on Virtual Machine 1.
- Identify the operating system running on Virtual Machine 2.
- Identify the operating system running on Virtual Machine 3.
- Understand how multiple operating systems can run on a single physical computer.

## Procedure

1. Opened **Settings** on the ITAdmin computer.
2. Selected **System > About**.
3. Reviewed **Windows specifications** and identified the operating system edition running on the base computer.
4. Opened **Hyper-V Manager**.
5. Selected **ITADMIN** from the left side of Hyper-V Manager to view the available virtual machines.
6. Double-clicked **Virtual Machine 1** to open the Virtual Machine Connection window.
7. Started the virtual machine.
8. Opened **Settings > System > About**.
9. Reviewed **Windows specifications** to identify the operating system edition.
10. Closed the Virtual Machine Connection window.
11. Repeated the same process for **Virtual Machine 2**.
12. Repeated the same process for **Virtual Machine 3**.
13. Recorded the operating system information for the ITAdmin computer and all three virtual machines.
