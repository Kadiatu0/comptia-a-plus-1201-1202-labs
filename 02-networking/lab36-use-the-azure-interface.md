# Lab 36 – Use the Azure Interface

## Scenario

You are the network administrator for your company. You are beginning to configure Microsoft Azure to help manage the network. Your task is to create a resource group to organize Azure assets.

## Objectives

- Access the Azure portal.
- Create a resource group.
- Configure the required subscription, resource group name, and region.
- Review the created resource group.

## Technologies

- Microsoft Azure
- Azure Portal
- Resource Groups
- Google Chrome

## Skills Demonstrated

- Navigating the Azure portal
- Creating Azure resource groups
- Configuring Azure project details
- Reviewing Azure resources

## Procedure

1. Open Google Chrome and access the Azure portal at `https://portal.azure.com`.
2. Under Navigate, select **Resource groups**.
3. Select **Create**.
4. Configure the project details:
   - Subscription: `CorpNet Production`
   - Resource group: `CorpNetCloud`
5. Configure the resource details:
   - Region: `(US) West US2`
6. Select **Review + create** to validate the configuration.
7. Select **Create**.
8. From the Resource groups page, select `CorpNetCloud`.
9. Review the options of the created resource group.

## Outcome

Successfully created the `CorpNetCloud` resource group in Azure using the `CorpNet Production` subscription and `(US) West US2` region.

## Key Takeaways

- Learned how to access the Azure portal.
- Practiced creating an Azure resource group.
- Learned how subscriptions, resource groups, and regions are configured.
- Practiced reviewing an Azure resource after creation.
