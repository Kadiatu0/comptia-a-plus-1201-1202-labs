# Lab 25 – Secure a Small Wireless Network

## Scenario

As an IT technician, I was tasked with configuring and securing a wireless network so a laptop could connect to the home office network.

---

## Objectives

- Configure a wireless network name (SSID).
- Enable wireless encryption.
- Create a secure Wi-Fi password.
- Connect a laptop to the wireless network.

---

## Technologies

- Wireless Router
- Wi-Fi
- 2.4 GHz Wireless Network
- WPA2-PSK
- SSID
- Chrome

---

## Skills Demonstrated

- Wireless Network Configuration
- Wi-Fi Security
- Router Administration
- Wireless Client Configuration

---

## Procedure

1. Accessed the router configuration page through Chrome using `192.168.0.254`.
2. Configured the 2.4 GHz wireless network with the SSID **Pretty Fly Wi-Fi**.
3. Applied the wireless configuration.
4. Enabled **WPA2-PSK** wireless security.
5. Configured the wireless password.
6. Applied the security settings.
7. Connected the Home-Laptop to the **Pretty Fly Wi-Fi** network.
8. Entered the wireless security key and confirmed the connection.

---

## Outcome

Successfully configured and secured the wireless network using WPA2-PSK and connected the laptop to the secured Wi-Fi network.

---

## Key Takeaways

- Learned how to configure an SSID on a wireless router.
- Practiced securing Wi-Fi with WPA2-PSK.
- Learned how to connect a wireless client to a secured network.
