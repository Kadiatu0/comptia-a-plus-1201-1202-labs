# Lab 28 – Connect Fiber Optic Cables

## Scenario

As an IT technician, I was tasked with setting up a SOHO fiber internet connection using a preconfigured fiber router.

---

## Objectives

- Connect the fiber router to the ISP fiber line.
- Connect the router to the computer.
- Provide power to the router.

---

## Technologies

- Fiber Router
- SC-to-SC Fiber Cable
- Cat6a Ethernet Cable
- AC-to-DC Power Adapter
- Fiber Internet

---

## Skills Demonstrated

- Fiber Network Installation
- Router Configuration
- Ethernet Connectivity
- Network Power Setup

---

## Procedure

1. Added the fiber router to the workspace.
2. Connected the router to the ISP fiber line using an **SC-to-SC fiber cable**.
3. Connected the computer to the fiber router using a **Cat6a Ethernet cable**.
4. Connected the router to the power strip using an **AC-to-DC power adapter**.
5. Verified all network and power connections were properly connected.

---

## Outcome

Successfully connected the fiber router to the ISP fiber line, computer, and power source, completing the SOHO fiber internet setup.

---

## Key Takeaways

- Learned how to connect a fiber router to an ISP fiber connection.
- Practiced using SC fiber connectors.
- Reinforced the difference between fiber and Ethernet connections.
