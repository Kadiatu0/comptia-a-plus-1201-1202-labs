# Lab 23 – Connect Patch Panel Cables

## Scenario

As a network technician, I was tasked with connecting a new workstation in Office 1 to the company's wired network and configuring it for automatic network addressing.

---

## Objectives

- Connect the patch panel to the network switch.
- Connect the workstation to the network.
- Configure automatic IP and DNS addressing.
- Verify network and internet connectivity.

---

## Technologies

- Cat6a Ethernet Cable
- RJ45 Connectors
- Patch Panel
- Cisco Switch
- DHCP
- Ethernet

---

## Skills Demonstrated

- Network Cable Installation
- Patch Panel Configuration
- Ethernet Connectivity
- DHCP Configuration
- Network Troubleshooting

---

## Procedure

1. Connected the **Off 1** patch-panel port to **port 3** on the Cisco switch using a Cat6a cable.
2. Connected the Office 1 workstation to the wall Ethernet outlet using a Cat6a cable.
3. Opened Windows network settings.
4. Changed the workstation's IP assignment to **Automatic (DHCP)**.
5. Verified that DNS addressing was also configured automatically.
6. Confirmed the workstation connected successfully to the local network and internet.

---

## Outcome

Successfully connected the Office 1 workstation to the wired network and configured it to automatically obtain IP and DNS settings through DHCP.

---

## Key Takeaways

- Learned how patch panels connect workstations to network switches.
- Practiced installing Cat6a Ethernet connections.
- Learned how to configure Windows for automatic DHCP addressing.
- Verified network and internet connectivity.
