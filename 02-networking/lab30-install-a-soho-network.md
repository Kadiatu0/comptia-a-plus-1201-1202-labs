# Lab 30 – Install a SOHO Network

## Scenario

In this challenge lab, I created a Small Office/Home Office (SOHO) network by connecting a router to the internet, configuring two desktop computers for DHCP, connecting a wireless access point, and securing the wireless network. I then connected a laptop and iPad to the wireless network and verified internet connectivity.

---

## Objectives

- Connect the router to the internet.
- Provide power to the router.
- Connect two desktop computers to the router.
- Configure both computers to obtain IP addresses automatically using DHCP.
- Configure both computers to obtain DNS servers automatically.
- Connect and power a wireless access point.
- Configure the wireless access point with a secure wireless network.
- Connect a laptop to the wireless network.
- Connect an iPad to the wireless network.
- Verify network and internet connectivity.

## Procedure

1. Connected the router to the internet:
   - Added the router to the workspace.
   - Connected the router to the surge protector using the power adapter.
   - Connected the router WAN port to the left network port on the wall plate using a Cat5e RJ45 cable.

2. Connected the desktop computers to the router:
   - Connected PC1 to a LAN port on the router using a Cat5e cable.
   - Connected PC2 to another LAN port on the router using a Cat5e cable.

3. Configured PC1 for automatic network configuration:
   - Opened **Settings > Network & internet > Ethernet**.
   - Edited the **IP assignment** settings.
   - Selected **Automatic (DHCP)**.
   - Saved the configuration.
   - Verified that PC1 had internet access.

4. Configured PC2 for automatic network configuration:
   - Opened the Windows network settings.
   - Changed the IP assignment to **Automatic (DHCP)**.
   - Saved the configuration.
   - Verified the network connection.

5. Connected the wireless access point to the router:
   - Added the wireless access point to the workspace.
   - Connected the power adapter to the access point and surge protector.
   - Connected the access point to a LAN port on the router using a Cat5e cable.

6. Configured the wireless access point:
   - Opened **Google Chrome** on PC1.
   - Accessed the management interface at **192.168.0.100**.
   - Logged in using:
     - Username: **admin**
     - Password: **password**
   - Opened **Wireless > Basic**.
   - Set the SSID to **HomeWireless**.
   - Applied the configuration.

7. Configured wireless security:
   - Opened **Wireless > Security**.
   - Selected **WPA2-PSK** as the authentication mode.
   - Selected **AES** as the encryption method.
   - Set the pass phrase to **@hOMEwIRELESS!**.
   - Applied the security configuration.

8. Connected the laptop to the wireless network:
   - Enabled the laptop's wireless switch.
   - Opened the available wireless networks.
   - Selected **HomeWireless**.
   - Enabled **Connect Automatically**.
   - Entered **@hOMEwIRELESS!** as the security key.
   - Connected to the wireless network.
   - Verified that the laptop had internet connectivity.

9. Connected the iPad to the wireless network:
   - Turned on the iPad.
   - Opened **Settings > Wi-Fi**.
   - Selected **HomeWireless**.
   - Entered **@hOMEwIRELESS!** as the password.
   - Selected **Join**.

10. Verified that the SOHO network devices were connected and communicating successfully.

## Outcome

Successfully installed and configured a basic SOHO network with a router, two wired desktop computers, a wireless access point, a laptop, and an iPad. Both desktop computers were configured to obtain their IP addresses and DNS settings automatically through DHCP. The wireless access point was configured with WPA2-PSK and AES encryption, and both wireless devices successfully connected to the **HomeWireless** network.
