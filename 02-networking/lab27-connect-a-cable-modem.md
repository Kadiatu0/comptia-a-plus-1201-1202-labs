# Lab 27 – Connect a Cable Modem

## Scenario

As an IT technician, I was tasked with setting up a SOHO cable internet connection using a preconfigured cable modem supplied by the ISP.

---

## Objectives

- Connect the cable modem to the ISP connection.
- Connect the computer to the modem.
- Provide power to the modem.
- Establish an internet connection.

---

## Technologies

- Cable Modem
- RG-6 Coaxial Cable
- Cat6a Ethernet Cable
- AC-to-DC Power Adapter
- ISP Connection

---

## Skills Demonstrated

- Cable Modem Installation
- Network Cable Configuration
- Power Adapter Connection
- Internet Connectivity Setup

---

## Procedure

1. Added the cable modem to the workspace.
2. Connected the modem to the ISP cable line using an **RG-6 coaxial cable**.
3. Connected the computer to the modem using a **Cat6a Ethernet cable**.
4. Connected the modem to power using the **AC-to-DC power adapter**.
5. Verified the modem was connected using its preconfigured ISP settings.
6. Confirmed the network was ready for internet access.

---

## Outcome

Successfully connected and powered the cable modem and established the required connections between the ISP, modem, and computer.

---

## Key Takeaways

- Learned how to install a cable modem in a SOHO network.
- Practiced using coaxial and Ethernet cables.
- Learned how a cable modem provides internet connectivity.
